# Avisos de licença

Uma licença diz o que cada pessoa pode fazer com um trabalho: usar, mudar, repassar. Este
projeto usa duas licenças diferentes, para dois tipos de arquivo diferentes, mais uma
exceção para o material de terceiros.

## 1. Programas — GPL-3.0

Os scripts deste projeto — os pequenos programas da pasta [`scripts/`](scripts/), os
arquivos `.py` — estão sob a GNU General Public License v3.0. Texto completo em
[`LICENSE`](LICENSE). Eles podem ser usados, estudados, mudados e repassados livremente,
mas qualquer versão mudada também precisa continuar sob a mesma licença, aberta pra todo
mundo, com o código dos programas disponível.

## 2. Conteúdo — CC BY-NC-SA 4.0

Tudo neste projeto que não é programa (item 1) nem material de terceiros (item 3) está
sob CC BY-NC-SA 4.0 — isso inclui os documentos de teoria, dicionário e ficha, as
planilhas de pergunta, a lista de referências (`docs/FONTES.md`), os arquivos de dados e
os documentos de apresentação. A regra vale por tipo de arquivo, não por uma lista
fechada: um arquivo novo do mesmo tipo já nasce coberto.

Texto completo em [`LICENSE-CONTENT.txt`](LICENSE-CONTENT.txt). Esse conteúdo pode ser
usado, adaptado e repassado, desde que se dê o crédito, não se use para fins comerciais,
e qualquer versão adaptada mantenha a mesma licença.

## 3. Material de terceiros — fora de qualquer licença deste projeto

Os arquivos em [`docs/material-base/`](docs/material-base/) — o material de aula, a
transcrição dele, as cópias do material de fora em `fontes-externas/`, a base de trechos
do material de fora e a prova dos cartões — não são cobertos por nenhuma das licenças
acima. [Origem do material: material de aula de qual disciplina e instituição, se quem
mantém o projeto é ou não o autor dele, e de onde vem o material de fora, se houver.] Por
isso:

- Esse material nunca é publicado nem repassado — fica só no computador de quem mantém o
  projeto. Se o projeto é guardado no GitHub, a lista do que nunca vai pra lá (o arquivo
  [`.gitignore`](.gitignore)) já deixa essa pasta de fora.
- Quem receber uma cópia deste projeto com essa pasta preenchida deve tratá-la como
  material pessoal de estudo, não como parte do que se pode repassar.

As referências desses materiais estão em [`docs/FONTES.md`](docs/FONTES.md), que é
conteúdo deste projeto e segue o item 2.

## Como dar o crédito

Ao reusar o conteúdo (item 2), escreva: "[Nome do Projeto], licenciado sob CC BY-NC-SA
4.0", com o link para este projeto.
