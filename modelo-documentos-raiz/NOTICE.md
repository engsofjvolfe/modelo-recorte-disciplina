Este projeto usa duas licenças diferentes, para dois tipos de arquivo diferentes, mais
uma exceção para material de terceiros.

Todo script Python deste repositório — os arquivos `.py` de [`scripts/`](scripts/) — está
sob a GNU General Public License v3.0. Texto completo em
[`LICENSE`](LICENSE). O código pode ser usado, estudado, modificado e redistribuído
livremente, mas qualquer trabalho derivado também precisa continuar sob GPL-3.0 e vir
com o código-fonte disponível.

## 2. Conteúdo gerado — CC BY-NC-SA 4.0

Tudo neste repositório que não é código Python (item 1) nem material de terceiros
(item 3) está sob CC BY-NC-SA 4.0 — isso inclui os documentos de teoria, dicionário e
ficha, as planilhas de pergunta, o documento de fontes (`docs/FONTES.md`), e os
documentos de navegação da raiz. A regra é por categoria, não por lista fechada de
arquivos: um arquivo novo do mesmo tipo já nasce coberto.

Texto completo em [`LICENSE-CONTENT.txt`](LICENSE-CONTENT.txt). Esse conteúdo pode ser
usado, adaptado e redistribuído, desde que se dê crédito, não se use para fins
comerciais, e qualquer versão adaptada mantenha a mesma licença.

## 3. Material de terceiros — fora de qualquer licença deste projeto

Os arquivos em [`docs/material-base/`](docs/material-base/) — o material de aula, a
transcrição literal dele, as cópias do material de fora em `fontes-externas/`, a base
de trechos literais dele e a prova dos cartões — não são cobertos por nenhuma das
licenças acima. [Origem do
material: material de aula de qual disciplina/instituição, se quem mantém o
repositório é ou não o autor, e de onde vem o material de fora, se houver.] Por isso:

- Essa pasta está no [`.gitignore`](.gitignore) e nunca é versionada, publicada ou
  redistribuída — fica só localmente.
- Quem recebe este projeto com essa pasta preenchida deve tratá-la como material
  pessoal de estudo, não como parte do pacote de código aberto.

As referências desses materiais estão em [`docs/FONTES.md`](docs/FONTES.md), que é
conteúdo deste projeto e segue o item 2.
